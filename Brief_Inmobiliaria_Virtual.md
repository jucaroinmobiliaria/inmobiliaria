Actúa como un **equipo senior completo de producto digital**, compuesto por:

* Product Designer / UX Lead
* UI Designer especializado en plataformas inmobiliarias premium
* UX Researcher
* Arquitecto de software Full Stack
* Desarrollador Frontend Senior
* Desarrollador Backend Senior

Quiero crear desde cero una **inmobiliaria virtual moderna y profesional** enfocada inicialmente en Colombia, cuya finalidad sea **publicar, vender y arrendar inmuebles**.

No quiero una página web genérica ni una plantilla típica de inmobiliaria. Quiero crear una experiencia comparable con las mejores plataformas inmobiliarias y marketplaces digitales, pero con una identidad propia, moderna, elegante, rápida e intuitiva.

* Buscar inmuebles para arrendar.
* Publicar inmuebles.
* Administrar publicaciones.
* Subir múltiples fotografías.
* Organizar automáticamente las fotografías.
* Agregar videos y/o recorridos virtuales.
* Gestionar características del inmueble.
* Recibir solicitudes de información.
* Contactar al anunciante.
* Agendar visitas.
* Guardar inmuebles favoritos.
* Comparar inmuebles.
* Compartir publicaciones.
* Gestionar usuarios.
* Gestionar propietarios/inmobiliarias.
* Administrar publicaciones desde un panel administrativo.
* Tener estadísticas de las publicaciones.

La experiencia debe estar diseñada pensando tanto en:

**PERSONA QUE BUSCA INMUEBLE**

**PERSONA QUE PUBLICA INMUEBLES**

# 23. RESULTADO ESPERADO

No quiero solamente código.

Quiero que construyas una **experiencia completa de producto inmobiliario**.

Primero analiza el producto y define la experiencia.

Después crea la interfaz.

Después implementa los componentes.

Después conecta los flujos.

Después revisa visualmente toda la experiencia.

Finalmente realiza una revisión como usuario real y detecta:

* problemas de UX
* pasos innecesarios
* inconsistencias
* problemas responsive
* problemas de accesibilidad
* problemas de conversión
* errores de navegación

y corrígelos.

La prioridad debe ser:

1. Experiencia del usuario
2. Diseño visual
3. Facilidad para publicar inmuebles
4. Facilidad para encontrar inmuebles
5. Conversión
6. Rendimiento
7. Escalabilidad
8. Seguridad

Quiero que el resultado final se sienta como un **producto inmobiliario tecnológico de nueva generación**, no como una página web tradicional.

Antes de generar código, muéstrame la propuesta de arquitectura de pantallas y el concepto visual general.
